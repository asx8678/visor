Geometry that answers the pointer

A small example website whose background is a live three.js scene: an faceted crystal, a drifting field of particles, and a camera that leans toward your cursor.

Read the walkthrough See the parts

How it works

One index.html, one canvas, one animation loop.

Scene and camera

A PerspectiveCamera at z=6 with a WebGLRenderer whose pixel ratio is capped at 2 so phones stay cool.

The crystal

An IcosahedronGeometry with a metallic standard material, plus an EdgesGeometry wireframe drawn on top.

Particles

Twelve hundred points in a spherical shell, one BufferGeometry, additive blending, no per-frame allocation.

Pointer parallax

Mouse and touch move a target the camera eases toward each frame, so motion stays soft and frame-rate independent.

The parts

Everything is in the script at the bottom of the page.

buildScene()

Creates the background gradient, lights, crystal and particles, then returns the moving parts.

onPointerMove()

Stores a normalized pointer position; the loop damps toward it.

tick()

Rotates, drifts and renders. Uses a clock delta so speed does not depend on refresh rate.

onResize()

Keeps the drawing buffer and the camera's aspect in step with the window.

Run it

Put the file next to a terminal and open it — it loads three.js from a CDN through an import map.

Fastest

Open index.html in a browser. Needs a network connection for the three.js module.

Local server

python3 -m http.server 8000 in this folder, then localhost:8000.

Offline

Download three.module.js beside the file and point the import map at ./three.module.js.
